# Licencias de las imágenes de RAÍZ

Las fotos originales están en esta carpeta. `docker compose run --rm web npm run imagenes` genera, a partir de ellas, las versiones AVIF, WebP y JPG
de cada tamaño en `public/img/`. Cada imagen tiene su licencia: la página de créditos (`creditos.html`) tiene que
reconocerlas todas.
